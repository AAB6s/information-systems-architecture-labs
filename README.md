# AutoLoc — TP04

Spring Boot 3.1.3 · Java 17 · MySQL (`localhost:3307`, `autoloc_db`).

Neuf services injectés par constructeur et neuf contrôleurs sous `/api`. Paiement en lecture seule.

Définir `AUTOLOC_DB_PASSWORD`, puis :

```bash
mvn spring-boot:run
```

Avant le rendu : `mvn clean`.
