# AutoLoc API

A Spring Boot project for the AutoLoc vehicle rental workshops. TP02 connects the entities created in TP01.

## Overview

The JPA model follows the workshop diagram: agencies manage employees and vehicles; clients reserve vehicles; reservations lead to contracts and payments.

## Main Features

- Nine entities linked through eight relationships.
- One join table for vehicle equipment.
- MySQL schema generated by Hibernate and kept in update mode after verification.

## Tech Stack

- Java 17
- Spring Boot 3.1.3
- Maven
- Spring Data JPA and MySQL
- Lombok

## Project Structure

```text
src/main/java/tn/esprit/autoloc/
  domain/          Entities, enums, and associations
  AutolocApiApplication.java
src/main/resources/application.properties
```

## Run Locally

Set `AUTOLOC_DB_PASSWORD` to your MySQL root password, then run:

```bash
mvn spring-boot:run
```

MySQL uses `localhost:3307` and the `autoloc_db` database on this PC.

## Useful Commands

```bash
mvn clean verify
mvn spring-boot:run
```

## Purpose

TP02 models the associations and verifies that MySQL contains ten tables, including the vehicle equipment join table.
